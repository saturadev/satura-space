Where each platform takes builds

How a build gets onto each platform, as of the date at the bottom, and where the current instructions are. Pages written for machines come first: an agent reads those.

PlatformUploadRead here
itch.iobutler CLI pushes a folder or zip. Open store, no review. The game page is set to HTML once, on the website.butler manual, HTML5 games
PokiPoki CLI, written for agents: run it with no arguments for its own structured help. You sign in once yourself. Curated: review is requested on Poki for Developers.Poki CLI, developer guide
PlaygamaMCP server for agents: create the game, upload builds and covers, publish a public sandbox link, read review comments. You allow it in the browser. Submitting to review stays in the console.llms.txt, MCP server
Facebook Instant GamesGraph API uploads a zip, and a separate call pushes a version to production. Needs a Meta app; the token stays out of the project.Upload bundle
Wavedashwavedash CLI pushes numbered builds; a build is promoted to published from the CLI or the portal.llms.txt
Your own siteAny static host. Cloudflare Pages deploys a folder with wrangler after a one-time sign-in.Cloudflare Pages llms.txt, limits
Yandex GamesDeveloper console: a draft with the archive, texts and images, then moderation.llms.txt, adding a game, requirements
CrazyGamesDeveloper portal with a QA tool. A game starts in a basic launch and may be picked for a full launch with the SDK and ads.Documentation, developer portal
GameDistributionDeveloper console.Developers
YouTube PlayablesThrough the Playables developer portal after onboarding; release goes through a partner manager.Playables
Telegram Mini AppsYou host the game and connect it to a bot.Mini Apps
Every platform has its own requirements for size, devices, content and store images, and they change. Read them on the platform's pages before building for it. Some forbid things a generated game might do: Yandex Games, for one, doesn't allow interactive AI inside games.
Principles checked 2026-11-26. Limits, revenue shares, SDK versions and commands change, so they are not copied here: every platform fact links to its owner's page. Read that page before you act on it.
